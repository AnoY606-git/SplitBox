# Изменения

## 1.2.2 — 2026-10-20

- Обновление через System сохраняет прежнее включённое или отключённое состояние приложения с помощью API Android 14+. Для ручной установки передаётся системная подсказка `INSTALL_SCENARIO_FAST`; измеренное ускорение не заявляется. Новых разрешений и настроек нет.
- Подтверждение System передаётся через immutable activity PendingIntent с сохранением Binder и токенов защиты в Android. Журнал хранит envelope v1 без extras и Parcel-байтов. Холодный поиск handle выполняется best effort; недоступный или legacy handle даёт UNKNOWN с сохранением файлов и обработкой позднего результата, без повторного commit и отмены запечатанной сессии. Решение описано в ADR 001 на русском и английском.
- ACK подтверждения изменяет журнал только при совпадении актуальной сессии, поколения и состояния: позднее событие не перезаписывает новый или окончательный результат. Различающиеся токены не объединяются при коллизии строкового хеша; добавлены JVM-регрессии и instrumented framework tests Android.
- Обновлены инструменты сборки: Gradle 9.6.1, Android Gradle Plugin 9.4.1, compileSdk/targetSdk 37 и встроенная поддержка Kotlin для Android. JDK 17 и minSdk 34 сохранены; JVM и Compose plugin остаются на Kotlin 2.2.21.
- Обновлены Compose BOM до 2026.09.00, Activity до 1.13.0, Core до 1.19.1, Lifecycle до 2.11.0, kotlinx.coroutines до 1.11.0 и apksig до 9.4.1.
- Адаптированы вызовы Material 3 `Text` в `LocalizedText`: именованные аргументы сохраняют назначение параметров после добавления `autoSize`. Удалён пустой вызов `super.onCleared()` для Lifecycle 2.11. Новые замечания lint `OldTargetApi` и `EmptySuperCall` устранены повышением targetSdk до 37 и удалением пустого вызова.
- Включены исправления lint после 1.2.1: обычные записи настроек используют KTX, подтверждённые записи журнала и истории сохраняют проверку результата `commit()` через общий helper с одним обоснованным локальным подавлением `UseKtx`. Глобальных отключений lint и baseline нет.
- Доступное место обновляется через `StatFs.restat()` перед записью с сохранением резерва 64 МиБ; один probe переиспользуется в операции. Проверка места при копировании набора APK обязательна; регрессии охватывают границы файлов, закрытие потока и очистку частично записанного каталога.
- Адаптивные иконки перенесены из `mipmap-anydpi-v26` в `mipmap-anydpi` без изменения XML. Обновлены русская и английская документация. Версия `1.2.2`, `versionCode 9`; для обновления с 1.2.1 сохраняется постоянный сертификат издателя. Проверки прежних APK остаются историческими, новые результаты фиксируются отдельно.

- Документация доступна на русском и английском: README, инструкции сборки, тестирования и выпуска, описание архитектуры и исторические отчёты о проверках связаны между собой.
- Исправлена упаковка исходников: `README.ru.md` включается в source ZIP; добавлена регрессионная проверка состава архива.
- Версия `1.2.1`, `versionCode 8`; для обновления с 1.2 сохраняется постоянный сертификат издателя. Исторические проверки прежних APK не выдаются за новый runtime-прогон релизного APK 1.2.1.

## 1.2 — 2026-10-20

- Добавлен английский интерфейс: экраны, настройки, статусы, ошибки и сообщения операций. Язык выбирается в приложении или системных настройках Android; доступен режим «Как в системе».
- Язык интерфейса отделён от системных языков устройства: переключение SplitBox на English не меняет автоматический подбор языковых APK.
- При выборе Root доступ проверяется автоматически. Для выбранного Shizuku проверяются служба и разрешение; после возврата в приложение статус обновляется.
- Отказ не вызывает бесконечные запросы. Сохранена явная повторная проверка, заблокированный доступ Shizuku требует изменения разрешения в Shizuku. Ответы от старой службы и одновременные повторные запросы отсеиваются.
- Версия `1.2`, `versionCode 7`; постоянный сертификат издателя сохраняется. Реклама, аналитика, аккаунты и сетевое разрешение не добавлены.

## 1.1.1 — 2026-10-19

- Исправлен отказ больших APK из-за общего лимита 4096 ZIP-записей. Ресурсы APK и количество устанавливаемых APK проверяются отдельно.
- Добавлены single-disk ZIP64, 64-битные размеры/смещения, проверка структуры каталогов и дополнительные регрессии повреждённых архивов.
- Автоматический лимит по свободному месту заменяет стандартные 2 ГиБ; доступны ручные значения до 64 ГиБ. У Shizuku снят предел 4 ГиБ, таймауты Root/Shizuku учитывают размер передачи.
- Прогресс передачи обновляется по байтам с ограничением частоты UI/Binder; экспорт OBB показывает свой фактический объём.
- При нехватке места до создания установочной сессии готовый пакет и выбор частей сохраняются для повтора без нового импорта.
- Исправлена очистка после отмены анализа. Неперенесённые OBB сохраняются вместе с пакетом и checkpoint для экспорта после перезапуска. Длительный перенос OBB можно отменить после успешной установки APK.
- При прерывании Root/Shizuku удаляется временный OBB текущей операции; существующий файл расширения сохраняется. Сообщение об отмене не раскрывает внутренние имена классов корутин.
- Карточка способа установки сохраняет читаемость на узком экране с крупным шрифтом.
- Добавлен воспроизводимый генератор собственных больших APK/APKS, расширены инструкции по регрессии. Версия приложения 1.1.1, versionCode 6.

## 1.1 — 2026-10-14

- Добавлен прямой импорт до 128 отдельных APK одного приложения через системный выбор файлов и «Поделиться». Каждый файл копируется один раз, с общим лимитом размера, проверкой версии, состава и подписей; промежуточный ZIP не создаётся.
- На главном экране выбор файлов доступен раньше: сокращено приветствие, действия перемещены выше карточки способа установки.
- Добавлен поиск по частям пакета. Он работает вместе с фильтром выбранных и не изменяет состав установки.
- История получила фильтры по результату и способу установки, счётчик совпадений, сброс фильтров и просмотр отчёта перед копированием. Неподтверждённые результаты выделены отдельно.
- В сведениях о подготовленном пакете доступны сравнение числовой версии с установленной и поиск разрешений, объявленных выбранными APK. Ограничения видимости Android и неполные сведения показываются явно.
- Во время ревью исправлены пограничные случаи канонизации Android-каталогов, деклараций разрешений с нулевым/отрицательным maxSdkVersion и ключей строк инспектора.
- Сохранены Android 14+, System/Root/Shizuku, локальная обработка и отсутствие рекламы. Новые зависимости и разрешения не добавлены.
- Версия приложения `1.1`, `versionCode 5`; обновление использует постоянный сертификат издателя.

## 1.0, сборка 4 — 2026-10-14

- Автовыбор учитывает общую архитектуру нативных библиотек всех модулей, включая библиотеки в основных APK.
- APK с ресурсным `versionName` принимаются: неразрешённое название версии не мешает проверке пакета и числовой версии.
- Восстановление System проверяет фактическое состояние Android-сессии: незапечатанная прерванная сессия завершается без повторного commit; запечатанная не отменяется автоматически.
- Выход из ожидания разрешения сохраняет указатель на готовый пакет вместе с очисткой ожидания, сохраняя возможность холодного восстановления выбора.
- Экспорт OBB возвращает актуальное состояние сохранения и проверки частей при успехе, ошибке и отмене. Неопределённый результат установки остаётся UNKNOWN; отмена экспорта не отменяет сессию установки.
- Добавлены регрессионные тесты и уточнены контракты восстановления и сценарии проверки.

## 1.0, сборка 3 — 2026-10-14

- APK/APKS/XAPK/APKM: анализ, проверка совместимости и выбор split APK.
- Установка через System, Root и Shizuku; экспорт OBB и привилегированный перенос.
- Локальная история, настройки проверки и кэша, Material 3, светлая/тёмная темы.
- Авторство AnoY606-git, GPL-3.0-only; без рекламы, аккаунтов и аналитики.
- Единая версия в Gradle: versionName `1.0`, versionCode `3`; номер отображается в «О SplitBox».
- Русские поясняющие комментарии и сообщения приложения, проверок и скриптов выпуска.
- SHA-256 вычисляется при потоковом копировании; собственный raw APK в staging повторно не копируется. Размер кэша читается из индекса, сканирование выполняется на IO.
- Ручной выбор сохраняется последовательной очередью с ревизиями, подтверждением записи, видимой ошибкой и повтором сохранения. Старые записи инвалидируются перед сменой операции.
- System journal использует общий снимок в памяти и последовательную запись на IO; переходы к записи APK, commit и системному подтверждению ждут сохранения.
- Root/Shizuku сохраняют UUID, session и фазы операции. Восстановление использует доказанный результат либо нейтральный UNKNOWN, без автоматического su или повторного commit. История устраняет дубликаты UUID и хранит неопределённый результат как nullable.
- Выбор частей сгруппирован, есть фильтр выбранных и закреплённая сводка установки. Вкладки сохраняют UI-состояние; проверка выбора выполняется асинхронно с защитой от устаревшего результата. Ошибки доступны до закрытия, сохранение можно повторить.
- Добавлен отдельный модуль Macrobenchmark и генерации Baseline Profile с тестовыми вариантами приложения. Реальный импорт отделён от синтетических UI-наборов 50/500/4096 APK-записей; наличие сценариев не означает доказанного ускорения на физическом устройстве.
- Обновлены инструкции для разработчика, CI и выпуска исходников по текущим контрактам.

Проверенные сценарии и ограничения: [VERIFICATION](docs/VERIFICATION.md). Методика измерений и тестовые варианты: [benchmark/README](benchmark/README.md).
