# Участие в разработке

Начните с [путеводителя](docs/README.md) и [сборки](docs/BUILDING.md). Изменения собственного кода распространяются под GPL-3.0-only; сохраняйте применимые copyright/NOTICE и лицензии зависимостей. Авторство проекта — в [AUTHORS](AUTHORS.md).

## Правила изменения кода

- `core` остаётся Kotlin/JVM без Android imports. UI передаёт действия во ViewModel, а backend реализует один способ установки.
- System/Root/Shizuku выбираются явно. Ошибка одного способа не разрешает скрыто повышать привилегии.
- Проверки путей, CRC, лимитов, метаданных и подписей не ослабляются ради ускорения.
- Важные lifecycle-инварианты перечислены в [архитектуре](docs/ARCHITECTURE.md). UNKNOWN не превращается в успех, commit не повторяется автоматически.
- Приложение работает локально, без рекламы, аналитики, аккаунтов и INTERNET permission.
- Поясняющие комментарии, KDoc/docstrings и собственные сообщения пишите на русском. Идентификаторы API, ключи форматов, команды и ответы внешних протоколов сохраняйте в исходном виде. Юридические Copyright/SPDX и канонические тексты лицензий не переводите.

Для исправления сначала воспроизведите дефект проверкой поведения. Тесты должны ловить регрессии, а не повторять реализацию. Для UI проверьте темы, крупный шрифт, TalkBack и доступность действий. Изменение производительности обосновывайте замерами.

## Перед pull request

```bash
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease
python3 -m unittest discover -s scripts/tests -v
python3 scripts/check_repository.py
```

Запускайте Gradle последовательно в одном checkout. Дополнительные device-сценарии выбирайте по [TESTING](docs/TESTING.md). Используйте собственные небольшие fixtures; бинарные test fixtures из `core/src/test/resources/fixtures/` нужны тестам и входят в Git.

В PR опишите проблему, итоговое поведение и выполненные проверки. Для bug report нужны версия SplitBox, Android/ROM/модель, способ установки, формат и размер пакета, шаги и текст ошибки. Перед отправкой удалите персональные URI/пути и ключи. Уязвимости сообщаются по [SECURITY](SECURITY.md).
